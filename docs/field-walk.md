# 野外走位：像素引擎

地图数据按格（MDT 通行位、MIF 传送点），但**角色位置是像素**。原生
`Field_Hero_procMOVE` → `Map_tileMove` 每帧按 6px（走）／8px（跑）逐 1px 推进，
用脚下 16×16 碰撞盒问 `Map_tileIsMoveRect`；被挡时再沿垂直方向扫 1..32px 侧滑。
本工程按同一套规则实现，主角坐标仍是“格单位浮点”（1 格 = 16px），只是不再对齐格中心。

## 组成

| 件 | 位置 | 职责 |
| --- | --- | --- |
| 纯几何核心 | [pixel_walk.gd](../game/field/runtime/pixel_walk/pixel_walk.gd) | `move_step()` 逐 1px 判碰撞；`slide_direction()` 原生 1..32px 侧滑扫向 |
| 运行时接线 | [field_runtime.gd](../game/field/runtime/field_runtime/field_runtime.gd) | 速度累加、`_walk_rect_free()` 16×16 盒、跨格同步、传送、跟随者与步态 |
| 动画 | `monster_animation.advance_motion()` | 按实际像素位移推进走跑 ANI 的 `cycle_distance` |

## 规则

- **碰撞盒**：脚点 `(actor*16+8, actor*16+8)` 为中心、16×16；覆盖到的格全部可走才算可走。
  地形用 `story.tile_blocked`，另把实体占位与未开放传送格当作阻挡。
- **速度**：`WALK_SPEED=7.5`／`RUN_SPEED=10.0` 格/秒 = 120／160 px/s；按 delta 累加，
  小数像素留在 `_walk_remainder_px`，不丢帧。
- **侧滑**：前进方向被挡时，先看“前进 1px + 上/下（或左/右）1px”，再按 2..32px 两侧交替扫；
  找到可站位置就把剩余距离沿侧向走掉（夹到剩余像素）。
- **停止**：松开方向键立刻停下，位置可以停在半格上；不再走完当前格。
- **跨格**：只有整数格变化时才 `story.after_move(..., sync_hero=false)` 同步存档坐标、
  触发区域事件并检查 MIF 传送点，避免每像素把角色写回格中心。
- **脚本走位**（剧情 opcode 的逐格移动）仍按格目的地插值，不走这条手动通道。

## 方向键堆栈（多键同时按）

`_walk_stack` 按按下的先后入栈，**移动方向永远取栈顶**；重复按同一方向只把它提到栈顶，
不重复入栈。松开某个方向就从栈里移除：

- 松开的是栈顶 → 自动回到底下仍按着的方向（朝向、走/跑动作一起切回）；
- 松开的是非栈顶 → 当前移动方向不变；
- 栈空 → 停步回待机；
- 键盘 `handle_key` 的按下/松开与触控方向键切换都走这套；`_clear_walk_input`（撞怪、换图、
  菜单等）清空整栈。

这样同时按住两个方向不会互相把对方清掉，也不会同时往斜向移动（原生是单轴移动）。

## 验证

- `tests/unit/test_pixel_walk.gd`：逐像素阻挡停止、0px、侧滑扫向与“横向先上”的顺序。
- 一次性集成自检（已删除）：真实 `field_runtime.tscn` + 假 story，确认按住右方向一帧移动
  6px（0.375 格、非格中心）、200 帧后被 x=10 的墙挡在碰撞盒贴墙处。

## 边界

- 实体占位按 16×16 方格算（与旧的整格判定一致），原版是否穿透 NPC 未取证。
- 未开放传送格按“暂时不能通行”处理，不做部分踏入。
- 速度档位仍走 `Engine.time_scale`（选项里的速度设定）。
